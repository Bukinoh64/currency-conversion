# Как запустить конвертер валют

## На Windows

1. Откройте папку проекта.
2. Дважды щёлкните **start.bat**.
3. Конвертер откроется в браузере. Не закрывайте чёрное окно, пока пользуетесь приложением.

Чтобы остановить приложение, закройте чёрное окно.

## На телефоне: открыть один файл

1. Передайте файл **mobile.html** на телефон — например, по USB, через Bluetooth или облачное хранилище.
2. Скачайте файл на телефон и откройте его в браузере.

На телефоне открывайте **mobile.html**, а не **index.html**. В мобильном файле уже собраны оформление и функции конвертера.

## На Mac

1. Установите Python, если он ещё не установлен.
2. Откройте приложение «Терминал» и перейдите в папку проекта.
3. Запустите команду:

   ```bash
   python3 -m http.server 4173
   ```

4. Откройте в браузере адрес `http://localhost:4173`.

## Важно

При запуске приложение автоматически загружает курсы с ExchangeRate-API. В карточке курса показаны дата и время обновления по времени вашего устройства. Сервис обновляет котировки примерно раз в сутки: это справочный рыночный курс, он может отличаться от курса банка и не учитывает комиссию.

Последний полученный курс сохраняется на устройстве для работы без интернета. Без подключения покажется сохранённый курс и его дата. Если приложение ещё не успело получить курсы, подключитесь к интернету и нажмите **«Обновить»**. Пересчёт по сохранённым курсам работает офлайн.

Чтобы добавить конвертер на главный экран телефона именно как приложение, его сначала нужно разместить в интернете по защищённой ссылке `https://`. Файл **mobile.html** можно просто открыть, но установить его с главного экрана таким способом нельзя.

## Если вы изменили приложение

Соберите обновлённый файл для телефона: откройте папку проекта, щёлкните правой кнопкой мыши файл **build-mobile.ps1** и выберите **«Выполнить с помощью PowerShell»**. Новый файл **mobile.html** появится в папке проекта.
